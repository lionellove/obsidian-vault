#### 语言和字符串的概念
| 类型    | 语言                                                             | 字符串                            |
| ----- | -------------------------------------------------------------- | ------------------------------ |
| 并     | L1∪L2 ={u \|u ∈L1 或u ∈L2}                                      |                                |
| 交     | L1∪L2 ={u \|u ∈L1 或u ∈L2}                                      |                                |
| 补     | 不属于 L 的字符串的集合                                                  |                                |
| *连接*  | $L_1 \circ L_2 ={uv \|  u \in L_1 \quad and \quad v \in L_2 }$ | 字符串的连接就是把后一个拼到前一个后面（$w_1 w_2$） |
| 指数运算  | $L^0$ ={$\varepsilon$} $L^n=L^{n-1}\circ L$                    | $w^0=\varepsilon$              |
| *星运算* | = {u1u2...uk \| k ≥ 0,且u1,u2,...,uk ∈ L}                       |                                |
| 反转    |                                                                | $W^R$ 就是把字符串反向                 |
|       |                                                                |                                |
#### $\varepsilon,\emptyset,\set{\varepsilon}$ 的区别
$\varepsilon 代表空串，\emptyset代表不包含任何字符串的语言，\set{\varepsilon}代表只包含空串的语言。$
