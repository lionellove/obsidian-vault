# 电子磁矩与电子自旋知识点汇总

---

## 一、电子轨道磁矩

### 1.1 经典推导

电子绕核运动产生电流，形成磁矩：

$$\text{电流：} I = \frac{e}{T} = \frac{ev}{2\pi r}$$

$$\text{磁矩：} \vec{\mu}_l = I \cdot S \cdot \vec{n} = \frac{ev}{2\pi r} \cdot \pi r^2 \cdot \vec{n} = \frac{e}{2m_e} \vec{L}$$

$$\boxed{\vec{\mu}_l = -\frac{e}{2m_e} \vec{L}}$$

**方向**：与轨道角动量 $\vec{L}$ 反向（因电子带负电）

---

### 1.2 量子理论结果

$$\vec{\mu}_l = -\frac{\mu_B}{\hbar} \vec{L}$$

**玻尔磁子**：
$$\mu_B = \frac{e\hbar}{2m_e} = 0.5788 \times 10^{-4} \, \text{eV} \cdot \text{T}^{-1}$$

**轨道角动量大小**：
$$|\vec{L}| = \sqrt{l(l+1)}\hbar, \quad l = 0, 1, 2, \cdots, n-1$$

**z 方向投影**：
$$\mu_{lz} = -\frac{\mu_B}{\hbar} L_z = -m_l \mu_B$$

$$m_l = 0, \pm 1, \pm 2, \cdots, \pm l \quad (\text{共 } 2l+1 \text{ 个值})$$

---

### 1.3 空间量子化

在外磁场中，轨道角动量只能取 **2 l+1** 个分立方向：

| l | mₗ 取值 | 空间取向数 |
|---|--------|-----------|
| 0 (s) | 0 | 1 |
| 1 (p) | -1, 0, +1 | 3 |
| 2 (d) | -2, -1, 0, +1, +2 | 5 |

---

## 二、Stern-Gerlach 实验

### 2.1 实验装置

```
高温炉 → 银原子束 → 非均匀磁场 → 探测屏
```

### 2.2 关键原理

**均匀磁场**：只受力矩，不受力

**非均匀磁场**：受力
$$F_z = \mu_z \frac{\partial B_z}{\partial z}$$

### 2.3 实验结果与矛盾

| 理论预期（仅轨道）         | 实际观测      |     |     |
| ----------------- | --------- | --- | --- |
| 银原子基态 l=0 → 1 条斑纹 | **2 条斑纹** |     |     |
| 奇数条 (2 l+1)       | **偶数条**   |     |     |

### 2.4 实验结论

1. 证明**空间量子化**存在
2. 证明存在**新的角动量自由度**
3. 暗示 $s = 1/2$（因为 2 s+1 = 2）

---

## 三、电子自旋假设（1925 年）

### 3.1 提出者

**乌伦贝克 (Uhlenbeck) & 古兹米特 (Goudsmit)**

### 3.2 基本假设

| 假设内容 | 数学表达 |
|---------|---------|
| 电子有内禀自旋角动量 | $ |\vec{S}| = \sqrt{s(s+1)}\hbar$ |
| 自旋量子数固定 | $s = 1/2$ |
| 自旋投影量子数 | $m_s = \pm 1/2$ |
| 自旋磁矩 | $\vec{\mu}_s = -g_s \frac{\mu_B}{\hbar} \vec{S}$ |

### 3.3 自旋角动量

$$|\vec{S}| = \sqrt{s(s+1)}\hbar = \sqrt{\frac{1}{2} \cdot \frac{3}{2}}\hbar = \frac{\sqrt{3}}{2}\hbar$$

$$S_z = m_s \hbar = \pm \frac{1}{2}\hbar$$

### 3.4 自旋磁矩

$$\vec{\mu}_s = -g_s \frac{\mu_B}{\hbar} \vec{S}, \quad g_s \approx 2$$

$$\mu_{s,z} = -g_s m_s \mu_B = -2 \times (\pm \frac{1}{2}) \mu_B = \mp \mu_B$$

---

### 3.5 理论基础（Dirac 方程，1928 年）

- Dirac 从**相对论量子力学**自然导出自旋
- 自旋是**内禀属性**，无经典对应
- 不能理解为"旋转的小球"（表面速度会超光速）

---

## 四、朗德 g 因子（Landé g-factor）

### 4.1 定义

磁矩与角动量的比值：
$$\vec{\mu}_j = -g_j \frac{\mu_B}{\hbar} \vec{J}$$

### 4.2 各种情况

| 情况 | g 值 | 公式 |
|-----|------|------|
| 纯轨道角动量 | $g_l = 1$ | $\vec{\mu}_l = -\frac{\mu_B}{\hbar} \vec{L}$ |
| 纯自旋角动量 | $g_s = 2$ | $\vec{\mu}_s = -2\frac{\mu_B}{\hbar} \vec{S}$ |
| 总角动量 | $g_j$ | 见下方公式 |

### 4.3 总角动量 g 因子公式

$$g_j = \frac{3}{2} + \frac{s(s+1) - l(l+1)}{2j(j+1)}$$

或等价形式：
$$g_j = 1 + \frac{j(j+1) + s(s+1) - l(l+1)}{2j(j+1)}$$

### 4.4 有效磁矩

$$\mu_{\text{eff}} = -g_j \mu_B \sqrt{j(j+1)}$$

$$\mu_{j,z} = -g_j m_j \mu_B, \quad m_j = -j, -j+1, \cdots, j$$

---

## 五、角动量耦合

### 5.1 总角动量

$$\vec{J} = \vec{L} + \vec{S} \quad (\text{矢量相加})$$

$$|\vec{J}| = \sqrt{j(j+1)}\hbar$$

### 5.2 j 的取值规则

$$j = l+s, \, l+s-1, \, l+s-2, \, \cdots, \, |l-s|$$

**步长为 1，共 $2\min(l,s)+1$ 个值**

### 5.3 单电子情况（s = 1/2）

| l | j 取值 | 光谱项 |
|---|-------|--------|
| 0 (s) | 1/2 | $^2S_{1/2}$ |
| 1 (p) | 3/2, 1/2 | $^2P_{3/2}, \, ^2P_{1/2}$ |
| 2 (d) | 5/2, 3/2 | $^2D_{5/2}, \, ^2D_{3/2}$ |
| 3 (f) | 7/2, 5/2 | $^2F_{7/2}, \, ^2F_{5/2}$ |

---

### 5.4 原子态符号

$$^{\mathbf{2S+1}}\mathbf{L}_{\mathbf{J}}$$

| 位置 | 含义 | 示例 |
|-----|------|------|
| 左上角 (2 S+1) | 自旋多重度 | ² 表示 S=1/2 |
| 中间 (L) | 轨道角动量 | S,P,D,F 对应 l=0,1,2,3 |
| 右下角 (J) | 总角动量 | j 的具体值 |

## 六、自旋-轨道耦合

### 6.1 物理图像

```
电子静止坐标系 → 原子实绕电子运动 → 产生磁场 B
                    ↓
         自旋磁矩 μ_s 与 B相互作用
                    ↓
              附加能量 ΔE
```

### 6.2 耦合能量公式

$$\Delta E_{s,l} = \frac{Z^{*4} R hc \alpha^2}{n^3 l(l+1)(2l+1)} \cdot [j(j+1) - l(l+1) - s(s+1)]$$

或等价形式：
$$\Delta E_{s,l} = \frac{1}{2} \xi(r) [j(j+1) - l(l+1) - s(s+1)]\hbar^2$$

其中 $\xi(r)$ 为自旋-轨道耦合常数。

### 6.3 能级分裂规律

$$\Delta E \propto \frac{Z^{*4}}{n^3 l(l+1)}$$

| 依赖关系 | 规律 |
|---------|------|
| Z*（有效核电荷） | Z* 越大，分裂越显著 |
| n（主量子数） | n 越大，分裂越小 |
| l（轨道角动量） | l 越大，分裂越小 |

---

## 七、碱金属光谱精细结构

### 7.1 钠黄线双线

| 谱线 | 波长 | 跃迁 |
|-----|------|------|
| D₁ | 589.6 nm | $3^2P_{1/2} \rightarrow 3^2S_{1/2}$ |
| D₂ | 589.0 nm | $3^2P_{3/2} \rightarrow 3^2S_{1/2}$ |

### 7.2 能级分裂原因

- **3 P 态**：l=1, s=1/2 → j=1/2, 3/2 **分裂为双层**
- **3 S 态**：l=0 → j=1/2 **不分裂**

### 7.3 跃迁选择定则

$$\Delta l = \pm 1$$

$$\Delta j = 0, \pm 1 \quad (j=0 \rightarrow j=0 \text{ 禁戒})$$

---

### 7.4 光谱线系

| 线系 | 跃迁 | 谱线特征 |
|-----|------|---------|
| 主线系 | np → ns | 双线 |
| 锐线系 | ns → np | 双线 |
| 漫线系 | nd → np | 三线 |
| 基线系 | nf → nd | 多线 |

## 八、电子反常磁矩

### 8.1 发现

1947 年，Kusch 和 Foley 精确测量发现：
$$g_s = 2.002319... \neq 2$$

### 8.2 反常磁矩定义

$$a = \frac{g_s - 2}{2} \approx 1.16 \times 10^{-3}$$

### 8.3 理论解释

- **Schwinger** 用量子电动力学(QED)解释
- 来自电子与外场相互作用的**高阶圈图贡献**
- 理论计算精度超过实验测量

### 8.4 精确测量值

$$a = 1159652188.4(43) \times 10^{-12}$$

## 九、能量量级比较

| 结构类型 | 能量量级 | 来源 |
|---------|---------|------|
| 粗结构 | $\alpha^0 E_0$ | 静电作用（库仑势） |
| 精细结构 | $\alpha^2 E_0$ | 自旋-轨道耦合 |
| 超精细结构 | $\alpha^4 E_0$ | 核磁矩与电子磁矩作用 |

其中 $\alpha = \frac{1}{137}$ 为精细结构常数，$E_0 = 13.6 \, \text{eV}$ 为氢原子基态能量。

## 十二、关键概念辨析

| 概念 | 符号 | 取值 | 来源 |
|-----|------|------|------|
| 轨道角动量量子数 | l | 0, 1, 2, ... | 薛定谔方程 |
| 自旋量子数 | s | 1/2 (电子固定) | 内禀属性 |
| 总角动量量子数 | j | \|l-s\| 到 l+s | 耦合结果 |
| 轨道磁量子数 | m_l | -l 到 +l | 空间量子化 |
| 自旋磁量子数 | m_s | ±1/2 | 自旋投影 |
| 总磁量子数 | m_j | -j 到 +j | 总角动量投影 |

---

> **总结**：电子自旋是量子力学中最重要也最反直觉的概念之一。它没有经典对应，是微观粒子的内禀属性。自旋-轨道耦合是原子光谱精细结构的主要来源，而朗德 g 因子统一描述了轨道和自旋对磁矩的贡献。
