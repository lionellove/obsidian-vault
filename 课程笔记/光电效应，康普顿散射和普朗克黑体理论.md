根据文档内容，我为你系统总结这三个量子物理的核心实验与理论。

## 一、普朗克黑体辐射理论

### 1. 热辐射的基本概念

**热辐射**：物体在任何温度下都要发射电磁波，波谱是连续谱。

**黑体**：完全吸收各种波长电磁波而无反射的物体（$a(\lambda,T) = 1$），空腔壁上的小孔可近似视为黑体。

### 2. 两个实验定律

| 定律 | 公式 | 物理意义 |
|------|------|----------|
| **Stefan-Boltzmann 定律** | $E(T) = \sigma T^4$ | 总辐射本领与 $T^4$ 成正比，$\sigma = 5.67\times 10^{-8}$ W/(m²K⁴) |
| **Wien 位移定律** | $\lambda_m T = b$ | 辐射峰值波长与 $T$ 的乘积为常数，$b = 2.898\times 10^{-3}$ m·K |

### 3. 经典理论的困境

**维恩公式**（1896 年）：
$$r(\lambda,T) = C_1 \lambda^{-5} e^{-C_2/\lambda T}$$
- 低频段偏离实验曲线

**Rayleigh-Jeans 公式**（1900 年）：
$$r(\lambda,T) = \frac{8\pi}{\lambda^4} kT$$
- 高频段趋于无穷 → **"紫外灾难"**！

### 4. 普朗克的突破

**普朗克公式**（1900 年 10 月 7 日）：
$$r(\lambda,T) = \frac{2\pi hc^2}{\lambda^5} \frac{1}{e^{hc/\lambda kT} - 1}$$

在全波段与实验惊人地符合！

**能量量子化假设**：
- 振子振动能量**不连续**，只能取最小能量 $\varepsilon_0$ 的整数倍
- $\varepsilon_0 = h\nu$（能量子）
- $h = 6.626\times 10^{-34}$ J·s（普朗克常数）

**关键区别**：

| 经典理论 | 普朗克理论 |
|----------|-----------|
| 能量连续取值 | 能量量子化：$\varepsilon = n h\nu$ |
| 平均能量 $\bar{\varepsilon} = kT$ | 平均能量 $\bar{\varepsilon} = \frac{h\nu}{e^{h\nu/kT}-1}$ |

## 二、光电效应

### 1. 实验现象

| 现象 | 内容 |
|------|------|
| **截止频率（红限）** | 仅当 $\nu > \nu_0$ 时才发生光电效应，$\nu_0$ 与材料有关，与光强无关 |
| **遏止电压 $U_0$ ** | 与入射光频率成线性关系，与光强无关 |
| **瞬时性** | 光照射后几乎立即有光电子逸出（<1 ns） |
| **饱和电流 $i_m$ ** | 与光强成正比（相同频率下） |

### 2. 经典理论的困难

| 问题 | 经典预测 | 实验事实 |
|------|----------|----------|
| **红限问题** | 只要强度足够大，任何频率都能产生光电效应 | 存在截止频率 $\nu_0$ |
| **瞬时性问题** | 电子需要时间积累能量（经典弛豫时间~50 min） | 响应时间<1 ns |

### 3. 爱因斯坦的光量子理论（1905 年）

**光量子假设**：光由一个个光子组成，每个光子能量 $E = h\nu$

**爱因斯坦方程**：
$$h\nu = W + \frac{1}{2}mv_{\max}^2$$

或写成：
$$E_k = h\nu - W$$

其中 $W$ 是**逸出功**（与材料有关）。

### 4. 对实验现象的解释

| 现象 | 解释 |
|------|------|
| **截止频率** | $W = h\nu_0$，产生条件：$\nu > \nu_0$ |
| **遏止电压** | $eU_0 = h\nu - W$，线性关系 |
| **瞬时性** | 一个光子能量被一个电子一次性吸收，无需时间积累 |
| **光强影响电流** | 光强越大 → 光子数目越多 → 光电子数目越多 |

### 5. 普朗克常数的测定

密立根实验（1916 年）：
$$U_0 = \frac{h}{e}\nu - \frac{W}{e}$$

测量 $U_0$ vs $\nu$ 的斜率可得 $h$，结果与其他方法一致，证实了光子理论。

## 三、康普顿散射

### 1. 实验现象（1922-1923 年）

X 射线在石墨上散射：
- 除原波长 $\lambda_0$ 外，出现新的波长 $\lambda > \lambda_0$
- 新波长随散射角 $\phi$ 增大而增大
- 波长偏移 $\Delta\lambda = \lambda - \lambda_0$ 只与 $\phi$ 有关，与散射物质无关

**康普顿波长偏移公式**：
$$\Delta\lambda = \lambda_c (1 - \cos\phi) = \frac{2h}{m_0c}\sin^2\frac{\phi}{2}$$

**电子康普顿波长**：
$$\lambda_c = \frac{h}{m_0c} = 2.41\times 10^{-3}\text{ nm} = 0.0241\text{ Å}$$

### 2. 经典理论的困难

经典电磁理论：电子受迫振动 → 辐射相同频率的光波 → $\lambda = \lambda_0$

无法解释波长改变现象！

### 3. 光子理论解释

**物理模型**：X 射线光子与"静止自由电子"弹性碰撞

**能量守恒**：
$$h\nu_0 + m_0c^2 = h\nu + mc^2$$

**动量守恒**：
$$\frac{h\nu_0}{c} = \frac{h\nu}{c} + m\vec{v}$$

**推导结果**：
$$\Delta\lambda = \frac{h}{m_0c}(1-\cos\phi)$$

理论值 $\lambda_c = 2.43\times 10^{-3}$ nm 与实验值 $2.41\times 10^{-3}$ nm 高度吻合。

### 4. 关键讨论

| 问题 | 解释 |
|------|------|
| **为什么还有 $\lambda_0$ 成分？** | 光子与内层电子（束缚紧）碰撞 → 实际与整个原子碰撞 → $m_{\text{原子}} \gg m_e$ → $\Delta\lambda \to 0$ |
| **为什么自由电子不吸收光子？** | 若自由电子吸收光子，无法同时满足能量和动量守恒（违反相对论） |
| **为什么可见光观察不到康普顿效应？** | 可见光波长~500 nm，远大于 $\lambda_c$，效应不显著 |

### 5. 实验意义

- 支持"光量子"概念，证实 $E = h\nu$
- **首次实验证实光子具有动量**：$p = E/c = h/\lambda$
- 证实微观单次碰撞中能量和动量守恒定律仍然成立

## 四、三个实验的联系：光子概念的建立

文档总结：

| 实验 | 贡献 |
|------|------|
| **黑体辐射** | 电磁波能量只能取 $E = nh\nu$ 的分立形式 |
| **光电效应** | 光由一个个光子组成，每个光子被电子整体吸收 |
| **康普顿散射** | 光子具有能量和动量，与电子碰撞满足守恒律 |

这三个实验共同确立了**光子的完整物理图像**：
- 能量：$E = h\nu$
- 动量：$p = h/\lambda = E/c$
- 光子是一个整体，在相互作用中满足能量和动量守恒

## 五、总结表格

| 主题 | 时间 | 栈心公式 | 核心突破 | 诺贝尔奖 |
|------|------|----------|----------|----------|
| **普朗克黑体理论** | 1900 年 | $r(\lambda,T) = \frac{2\pi hc^2}{\lambda^5(e^{hc/\lambda kT}-1)}$ | 能量量子化 $\varepsilon = h\nu$ | 1918 年 |
| **光电效应** | 1905 年 | $h\nu = W + E_k$ | 光量子假设，光子被整体吸收 | 1921 年（爱因斯坦） |

**共同意义**：这三个实验是量子物理的基石，揭示了光的粒子性，为玻尔原子理论（1913 年）提供了实验基础。
