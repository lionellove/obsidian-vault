## 一、光谱的基本类型

文档给出了三种光谱类型：

| 类型 | 特征 | 来源 |
|------|------|------|
| **线状光谱** | 谱线明晰成细线状 | 原子发出 |
| **带状光谱** | 谱线分段密集，呈连续带状 | 分子发出 |
| **连续光谱** | 波长连续变化 | 固体热辐射；原子/分子某些情况 |

## 二、氢原子光谱

### 1. 历史发现

- **1853年**：瑞典人埃格斯特朗（Ångström）测得氢可见光光谱的红线
- **Å单位**由此而来（$1\text{ Å} = 10^{-10}\text{ m}$）

**氢可见光光谱四条线**：

| 谱线 | 波长 | 颜色 |
|------|------|------|
| Hα | 6562.8 Å | 红 |
| Hβ | 4861.3 Å | 深绿 |
| Hγ | 4340.5 Å | 紫 |
| Hδ | 4101.7 Å | 紫 |

**分立光谱** → 暗示量子化能级！

### 2. 巴耳末公式（1885年）

瑞士数学家巴耳末发现氢原子可见光光谱规律：

$$\lambda = 364.57 \frac{n^2}{n^2 - 2^2}, \quad n = 3, 4, 5, \ldots$$

### 3. 里德伯公式（1890年）

瑞典物理学家里德伯给出更一般的氢原子光谱公式：

$$\tilde{\nu} = \frac{1}{\lambda} = R\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right)$$

其中：
- $\tilde{\nu}$：波数（单位：m⁻¹）
- $R = 1.0973731534\times 10^7\text{ m}^{-1}$：里德伯常量
- $n_i > n_f$：量子数

## 四、玻尔理论对光谱的解释

### 1. 玻尔的三个基本假设（1913年）

| 假设 | 内容 |
|------|------|
| **定态条件** | 原子存在一系列确定能量的稳定状态（不辐射） |
| **频率条件** | 定态跃迁时，发射或吸收的光子频率满足 $h\nu = E_n - E_m$ |
| **角动量量子化** | $L = mvr = n\hbar = n\frac{h}{2\pi}, n=1,2,3,\ldots$ |

### 2. 氢原子能级公式

$$E_n = -\frac{m_e e^4}{2(4\pi\varepsilon_0)^2\hbar^2} \cdot \frac{1}{n^2} = -\frac{hcR}{n^2} = -\frac{13.6\text{ eV}}{n^2}$$

**物理意义**：

| 量子数 $n$ | 能量 $E_n$ | 名称 |
|-----------|-----------|------|
| $n=1$ | $-13.6$ eV | 基态 |
| $n=2$ | $-3.4$ eV | 第一激发态 |
| $n=3$ | $-1.51$ eV | 第二激发态 |
| $n \to \infty$ | $E \to 0$ | 电离态（自由态） |

### 3. 能级跃迁与光谱线

**跃迁规则**：电子从高能级 $n_i$ 跃迁到低能级 $n_f$ 时，发射光子：

$$h\nu = E_{n_i} - E_{n_f} = hcR\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right)$$

**与里德伯公式完全一致！**

各线系对应跃迁：

| 线系 | 终态 $n_f$ | 跃迁起始态 |
|------|-----------|-----------|
| 莱曼系 | $n_f = 1$ | $n_i = 2, 3, 4, \ldots$ |
| 巴耳末系 | $n_f = 2$ | $n_i = 3, 4, 5, \ldots$ |
| 帕邢系 | $n_f = 3$ | $n_i = 4, 5, 6, \ldots$ |

从文档的能级图分析：

## 六、里德伯常量的修正

### 1. 玻尔理论值与实验值的误差

玻尔理论计算值与实验值有 **万分之五** 的误差。

### 2. 原因：原子核质量有限

玻尔假设电子绕固定核运动，但实际氢核质量有限（约1836倍电子质量），应作为**两体问题**处理。

### 3. 约化质量修正

$$\mu = \frac{M_H m_e}{M_H + m_e}$$

修正后的里德伯常数：

$$R_H = R_\infty \cdot \frac{1}{1 + m_e/M_H}$$

其中 $R_\infty$ 是核质量无穷大时的里德伯常数：

$$R_\infty = \frac{2\pi^2 m_e e^4}{(4\pi\varepsilon_0)^2 h^3 c} = 1.0973731\times 10^7\text{ m}^{-1}$$

修正后与实验值高度吻合，消除万分之五误差。

## 七、光谱的应用

### 1. 测定原子核质量（同位素识别）

由里德伯常数公式：
$$R = R_\infty \frac{1}{1 + m_e/M}$$

不同同位素的核质量不同 → 里德伯常数不同 → 谱线波长微小差异。

**氘的发现**（1932年）：
- 氢Hα线：656.279 nm
- 氘Hα线：656.100 nm
- 差异：0.179 nm
- 尤雷（Urey）通过光谱确认氘的存在 → **1934年诺贝尔化学奖**

### 2. 类氢离子的光谱

**类氢离子**：核电荷数 $Z > 1$，核外只有一个电子（如 He⁺, Li²⁺, Be³⁺）

光谱公式：
$$\tilde{\nu} = Z^2 R\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right)$$

**示例**：
- Li²⁺：$\tilde{\nu} = 9R_Li\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right)$
- Be³⁺：$\tilde{\nu} = 16R_{Be}\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right)$

### 3. 连续光谱（自由-束缚跃迁）

自由电子与氢离子结合 → 电子从非量子化轨道跃迁到量子化轨道：

$$h\nu = \frac{1}{2}m_e v_0^2 + \frac{hcR}{n^2}$$

**现象**：在巴耳末等系限外存在连续谱。

## 八、里德伯原子

**定义**：原子中有一个电子被激发到很高能级（$n$ 很大）的原子。

**特征**：

| 性质 | 与 $n$ 的关系 |
|------|---------------|
| 轨道半径 | $r_n \propto n^2$（很大） |
| 平均寿命 | $\propto n^{4.5}$（较长） |
| 相邻能级差 | $\propto 1/n^3$（很小） |

**实验进展**：
- 实验室制备出 $n > 100$ 的氢原子
- 射电天文观测探测到 $n > 600$ 的高激发态原子

**应用**：
- 敏感探测外界电磁场
- 同位素分离
- 产生高强度激光

## 九、弗兰克-赫兹实验：能级的直接验证

### 1. 实验目的（1914年）

用电子碰撞原子，验证原子能级量子化。

### 2. 实验结果

汞原子只吸收 **4.9 eV** 的能量 → 能级量子化！

观察到波长 2537 Å 的汞原子光谱，对应能量：
$$E = \frac{hc}{\lambda} = \frac{1240\text{ eV·nm}}{253.7\text{ nm}} \approx 4.9\text{ eV}$$

### 3. 物理过程

| 加速电压 | 碰撞类型 | 结果 |
|----------|----------|------|
| $V < 4.9$ V | 弹性碰撞 | 电子几乎不损失能量，电流上升 |
| $V = 4.9$ V | 非弹性碰撞 | 电子能量全部传递给汞原子，电流骤降 |
| $V > 4.9$ V | 混合碰撞 | 多次碰撞，电流周期性下降 |

## 十、玻尔理论的成功与局限

### 成功

| 方面 | 成果 |
|------|------|
| 氢光谱 | 完满解释巴耳末公式及各线系 |
| 里德伯常数 | 用已知物理量计算，与实验符合 |
| 原子半径 | 给出玻尔半径 $a_1 = 0.53$ Å |
| 电离能 | 定量给出 13.6 eV |
| 能级概念 | 正确指出定态和能量量子化 |

### 局限

| 问题 | 说明 |
|------|------|
| 经典轨道 | 保留经典轨道概念，不正确 |
| 半经典理论 | 缺乏逻辑一致性 |
| 光谱强度 | 不能解释谱线强度、极化、选择定则 |
| 复杂原子 | 不能解释多电子原子光谱 |
