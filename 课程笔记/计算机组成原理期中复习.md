#### C01 计算机系统概论
[[计算机系统和冯诺依曼结构]]
现代计算机中，计算单元和 控制单元（CU）共同组成 CPU，CPU 与存储组成主机，加上 I/O 设备组成硬件，所以冯诺依曼结构可以换一种绘制方式
[[指令执行过程]]
计算机中执行指令的过程需要结合具体指令系统来做，要先设计好指令系统。

| 操作  | ACC      | MQ               | X           |
| --- | -------- | ---------------- | ----------- |
| 加法  | 被加数，和    | \                | 加数          |
| 减法  | 被减数，差    | \                | 减数          |
| 乘法  | 被乘数，乘积高位 | 乘数（[M]->MQ），乘积低位 | 被乘数（ACC->X） |

##### 计算机硬件的技术指标
机器字长：寄存器位数有关（注意 PC 和 MAR 存的是地址，位宽和其他寄存器不一样）。
运算速度，由时钟主频，MIPS，CPI，FLOPS 等指标决定。
存储容量：二进制信息的总位数。
$CPI = \frac{Clock Cycles}{Instruction Count}$
CPU Time = Instruction count * CPI / Clock Rate=Instruction count * CPI * Cycle Time
对机器来说，CPI 是取加权平均值。
MIPS= $\frac{Clock Rate}{CPI * 10^6}$ ，但不能比较不同 ISA 架构的电脑，也不能比较同一个 ISA 中的不同指令，所以不可靠。（要学会计算）
